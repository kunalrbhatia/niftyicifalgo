### Description
Implement Strategy Brain (`strategy-brain`), an LLM-driven self-healing options strategy manager that continuously monitors positions, evaluates MTM danger thresholds and short strike wall proximity, and autonomously triggers research, backtest simulation, multi-factor scoring, paper execution, post-execution verification, and append-only decision ledger logging.

### Changes
- Created `strategy-brain` TypeScript (ESM) package with strict safety architecture, execution caps, and tier resolution (`strategy-brain/src/safety.ts`).
- Added portfolio state collector with Black-Scholes Greeks and short strike proximity monitoring (`strategy-brain/src/sitrep.ts`).
- Added curated Markdown strategy playbooks (`strategy-brain/playbook/`) for Iron Condor, Calendar Ratio Strangle, and Straddle adjustments.
- Built research engine with 24h search caching (`strategy-brain/src/research.ts`) and data lake historical analogue backtest simulator (`strategy-brain/src/backtest.ts`).
- Implemented multi-factor candidate scoring and ranking module (`strategy-brain/src/scorer.ts`).
- Created order executor with paper fill simulation (`strategy-brain/src/executor.ts`) and state verification (`strategy-brain/src/verify.ts`).
- Implemented JSONL append-only decision ledger (`strategy-brain/src/ledger.ts`) and Telegram alerts (`strategy-brain/src/telegram.ts`).
- Integrated orchestrator (`strategy-brain/src/orchestrator.ts`) with `--sitrep-only` and `--paper-cycle` CLI flags and PM2 config (`strategy-brain/ecosystem.config.cjs`).
- Added unit tests (`strategy-brain/test/`) for safety rails, decision ledger, and candidate scorer.
- Updated `README.md` with Strategy Brain architecture and documentation.
